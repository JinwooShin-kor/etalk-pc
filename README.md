## 도메인을 붙일 때

**깃허브 페이지는 저장소 하나에 도메인 하나다.** 그래서 방침도 여기로
옮겨 왔다 — 따로 두면 `etalk.kr` 을 둘로 나눠 줄 수가 없다.

1. `CNAME` 파일을 만들고 `etalk.kr` 한 줄만 적는다
2. 도메인 파는 곳(가비아·후이즈)에서 DNS 를 잡는다

```
A     @    185.199.108.153
A     @    185.199.109.153
A     @    185.199.110.153
A     @    185.199.111.153
CNAME www  jinwooshin-kor.github.io.
```

3. 저장소 설정 → Pages → Custom domain 에 `etalk.kr`, **Enforce HTTPS** 켜기

## 옛 주소는 살려 둔다

**스토어에 낸 방침 주소는 아직 `jinwooshin-kor.github.io/etalk-legal/` 이다.**
그 저장소를 그대로 두어야 심사가 안 깨진다. 애플 심사가 통과한 **뒤에**
스토어의 주소를 `https://etalk.kr/privacy/` 로 바꾸고, 그때
`etalk-legal` 은 새 주소로 넘겨보내는 한 장짜리로 바꾼다.

심사 중에 스토어 정보를 고치면 **심사가 취소되고 처음부터 다시 간다.**
